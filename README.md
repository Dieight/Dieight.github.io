# dieight.github.io

Personal homepage & blog built with vanilla HTML, CSS, and JavaScript.

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties, Animations)
- Vanilla JavaScript (Intersection Observer, Typing Effect)

## Local Development

```bash
# Serve locally with any static server
npx serve .
# or
python -m http.server 8000
```

## Deployment

Push to `main` branch — GitHub Pages auto-deploys.

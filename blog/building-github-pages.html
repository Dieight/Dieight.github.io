How I Built This Site with GitHub Pages

从买域名到上线——一个全流程记录，涵盖仓库配置、HTTPS 证书、自动部署和设计一致性。

Why GitHub Pages

搭建个人主页的理由很简单：你可以在一个免费、自带 HTTPS、能自动部署的地方放静态文件， 域名还支持自定义。GitHub Pages 正合适——它没有服务器费用，没有带宽限制， 跑的是纯粹的 HTML、CSS 和 JavaScript。

除此之外，它还有些不那么明显的好处：

  • 每次 git push 自动触发部署，不需要 CI 文件
  • 内置 Jekyll 支持，不想用也可以关闭
  • 自定义域名 + 强制 HTTPS 开箱即用
  • _config.yml 和 CNAME 文件直接控制行为

第一步：仓库命名

GitHub Pages 有两种模式：用户主页和项目主页。用户主页要求仓库名必须是 <username>.github.io。比如我的用户名是 Dieight， 仓库就是 Dieight.github.io。

命名对了之后，main（或 master）分支里放什么， https://dieight.github.io 就显示什么。 

git init
git remote add origin https://github.com/Dieight/Dieight.github.io.git
git add .
git commit -m "initial"
git push -u origin main

推完之后去仓库 Settings > Pages，选 Deploy from a branch、 分支 main、目录 / (root)，点 Save。等一两分钟就能访问了。

设计：从零到 DESIGN.md

页面本身很简单：一个 HTML、一个 CSS、一个 JS。但最初的版本有个问题—— 颜色是随手选的，间距没有尺度，渐变和动画用了一堆。看起来很"热闹"，但不专业。

这时我发现了 awesome-design-md—— 一个收录了 70+ 个品牌 Design System 的项目。每个品牌都有一份 DESIGN.md，描述颜色、字体、圆角、间距、组件规格，全部是纯文本令牌。

我选择了 Linear 的设计语言——接近纯黑的画布（#010102）， 炭灰色卡片（#0f1011），薰衣草蓝（#5e6ad2）作为唯一的彩色元素。 关键约束包括：

  • 无阴影，用表面阶梯 + 发丝边框来建立层次
  • 按钮 8px 圆角，卡片 12px，绝不用 pill 形状
  • 展示标题负间距（-1.8px / -1.0px），字重 600
  • 薰衣草色只用在品牌名、主 CTA 和聚焦环——绝不用于装饰
/* Linear DESIGN.md 中的颜色令牌 */
--canvas:       #010102;   /* 页面背景 */
--surface-1:    #0f1011;   /* 卡片背景 */
--ink:          #f7f8f8;   /* 标题文字 */
--ink-muted:    #d0d6e0;   /* 正文 */
--ink-subtle:   #8a8f98;   /* 辅助文字 */
--primary:      #5e6ad2;   /* 品牌色 */
--hairline:     #23252a;   /* 1px 边框 */

把所有规则照搬过来之后，整个页面的气质完全不同了——安静、精密、克制。 这就是 Design System 的价值：你不是在设计单个页面，而是在用一套已经验证过的规则做填空题。

博客方案

和页面一样，博客也可以直接放在仓库里。我在 /blog/ 下建子目录， 每篇文章就是一个 HTML 文件。列表页 blog/index.html 手动维护文章列表。

这样做有几点好处：

  • 零依赖。没有生成器、没有数据库、没有后端
  • 完全控制渲染。每一行 HTML 都是自己写的，样式和主页完全一致
  • 版本历史。每篇文章的修改都在 git log 里
  • 性能最优。纯静态文件，加载速度就是网络延迟

代价当然也有：没有编辑器、没有标签系统、没有 RSS——但作为一个个人主页的附属博客， 这些都不需要。需要文章多了以后再加一个静态生成器（如 Eleventy）也不迟。

总结

用 GitHub Pages 搭建个人主页其实就三步：

  1. 创建一个名为 username.github.io 的仓库
  2. 写 HTML、CSS，推上去
  3. 选一个 DESIGN.md，把颜色和间距对齐

整个过程没有花钱，没有配置服务器，没有调试 DevOps——只用了浏览器和终端。 如果你想搭一个，可以 从这里 开始找灵感。
